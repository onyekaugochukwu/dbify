# dbify

**SQL in your browser, for learning and teaching.** Three real database engines (SQLite, DuckDB and PostgreSQL) run inside the browser tab. Nothing to install, nothing uploaded, and it works offline.

**Open it:** https://onyekaugochukwu.github.io/dbify/

## Three ways to use it

| | How | Internet needed? |
|---|---|---|
| **Website** | Open the link above | First visit only |
| **Installed app** | Open the link in Chrome or Edge, then click the install icon in the address bar. dbify gets its own desktop / Start-menu icon. | First visit only |
| **Single file** | Download [`dbify.html`](https://onyekaugochukwu.github.io/dbify/dbify.html) (about 20 MB) and double-click it. Copy it to USB sticks or lab machines. | Never |

## Features

- **SQLite, DuckDB and PostgreSQL 17** running locally in WebAssembly. Each query tab picks its engine.
- **Editor**: syntax highlighting, autocomplete for keywords, tables and columns, keywords capitalised automatically as you type (can be switched off), Format SQL, run all / run selection / run the statement under the cursor.
- **Beginner-friendly errors**: "There is no column called `nmae`. Did you mean `name`?", with the mistake underlined in the editor. The original engine message is one click away.
- **Import** CSV, TSV, Excel (`.xlsx`, `.xls`, every sheet becomes a table), JSON / NDJSON and Parquet. Drag a file onto the page or use the ⋯ menu next to a database. Column types are detected automatically and names are cleaned up (`Transaction ID` → `transaction_id`).
- **Results grid** that stays fast with large results, sortable columns, and export to CSV, JSON or Excel.
- **Your work is kept**: databases and open tabs are saved in the browser automatically. *Save database to file* / *Open database file* moves them between computers.
- **Lessons**: the fictional *Naija Mart* online-store database (customers, products, orders, order items, payments) and 22 exercises from `SELECT *` to window functions, with hints, answers and automatic answer checking. Every answer runs unchanged on all three engines.
- Dark and light themes.

## For teachers

- Students need nothing but a browser. Chrome and Edge on Windows, macOS, Linux and ChromeOS are tested; Firefox and Safari should work.
- For labs with no internet, put `dbify.html` on the machines or a shared drive.
- Everything runs on the student's own machine. No accounts, no server, no data leaves the browser.
- Exercises live in [`src/lessons/exercises.ts`](src/lessons/exercises.ts); the sample data is generated by [`scripts/make-sample.js`](scripts/make-sample.js).

### Saved database file formats

| Engine | File | Can be opened by |
|---|---|---|
| SQLite | `.sqlite` | Any SQLite tool (DB Browser for SQLite, the `sqlite3` CLI, DBeaver…) |
| PostgreSQL | `.tar.gz` (a PGlite data directory) | dbify, or any PGlite app |
| DuckDB | `.duckdb.tar.gz` (output of `EXPORT DATABASE`) | dbify; or extract it and run `IMPORT DATABASE 'folder'` in the DuckDB CLI |

dbify can also open real `.duckdb` files.

## Development

```bash
npm install
npm run dev        # development server
npm run build      # dist/ (website + PWA) and dist/dbify.html (single file)
npm test           # end-to-end tests in Chrome, for both builds
npm run check      # type-check
```

Pushing to `main` builds, tests and deploys to GitHub Pages (see `.github/workflows/deploy.yml`).

### How it works

- **Engines**: [sql.js](https://github.com/sql-js/sql.js) (SQLite), [duckdb-wasm](https://github.com/duckdb/duckdb-wasm) and [PGlite](https://github.com/electric-sql/pglite) (PostgreSQL). Each runs in its own Web Worker so the page never freezes.
- **Small downloads**: engine binaries are stored gzip-compressed and unpacked in the browser (about 14 MB in total instead of 52 MB). Each engine is only loaded when first used.
- **Single file**: the same app with every binary embedded as base64. It uses classic workers and serves DuckDB its WASM from memory, because Chrome restricts module workers and `blob:` fetches on pages opened from disk.
- **Offline**: a service worker caches the whole site, so the installed app works with no connection.
- **Parquet and JSON** files are parsed in JavaScript ([hyparquet](https://github.com/hyparam/hyparquet)), and Excel files with [SheetJS](https://sheetjs.com). DuckDB's own Parquet and JSON readers are separate downloads from the internet, so they aren't used.
- UI: Svelte 5 and CodeMirror 6.
